**CivicPulse** is a mission-critical platform developed to manage the coordination, logistics, and distribution of food assistance to over 250 families. 

## 🛠 Tech Stack & Infrastructure
* **Frontend:** Angular (Containerized with Bind Mounts for rapid dev)
* **Backend:** Node.js & Express
* **Database:** MongoDB with persistent volumes
* **Orchestration:** Docker Compose
* **Infrastructure:** AlmaLinux 9 on VirtualBox
* **Security:** Nginx Reverse Proxy with SSL
* **Resiliency:** Dedicated Backup VM with NFS remote syncing
